# ZS Portfolio

A personal portfolio website designed to showcase my professional journey, experience, projects, education, and certifications in one place. Built with modern web technologies, ZS Portfolio provides visitors with an overview of my background, highlights my work, and offers convenient ways to get in touch.

## 🌐 Live Demo

**Website:** [ZS Portfolio](https://muhamadzulsaban.freehosting.dev/)

## ✨ Features

- **Experience** — Showcase professional experience and relevant activities.
- **Projects** — Present projects and work highlights.
- **Education** — Display educational background.
- **Certificates** — Showcase certificates and achievements.
- **Contact Me** — Provide a way for visitors to get in touch.
- **WhatsApp Contact** — Allow visitors to contact me through WhatsApp.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/muhamadzulunpam/zs_portofolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd zs_portofolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```

> **Setup note:** Replace `zs_portofolio` with the actual GitHub repository name. The development command assumes the project defines a `dev` script in `package.json`.
